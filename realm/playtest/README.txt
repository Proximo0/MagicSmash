HORDE & HEARTH playtest

1. Unzip this whole folder anywhere (for example your Desktop).
2. Double-click Play.cmd. It finds the game server that the Linux PC runs on your home network and starts the game.
   If Windows shows "Windows protected your PC", choose More info, then Run anyway (the game is not signed yet).
3. Spell a name on the board to log in (no password on the home server), make a hero, walk to a field gate.

The home server runs in two-hour sessions and starts a fresh world each time, so a hero lasts one session.
If the game cannot connect, close it and run Play.cmd again: it waits for the next session.
