# What each watching station runs on every merge: <STATION_NAME>: jobs [--after=<station>] [--p95=<frame limit ms, 0 = record only>]
# A station restarts itself when this file changes. No --after means it does not wait for another station.
# Four of Wands is stopped (21 Nov 2026): no station runs boss, checks or golden. `frames` now means Horde & Hearth's client drawing 10,000 monsters on the station's own
# graphics (record only unless a role adds --p95=<ms>, a limit on the 99th-percentile frame), so the laptop and the Celeron record theirs. A job is skipped for a merge
# that changed nothing it tests. `deep`: between merges the station runs seeded soaks (big store crash fuzz, full-size
# field bench) and reports them in <machine>-deep.txt instead of sleeping, so a merge of docs or art costs the stations nothing.
# `soak` runs inside `deep` now (time-boxed, fresh seed; STATION_DEEP_SOAK_SECS, default 900), so no role lists it. A deep FAIL also appends a line to <machine>-failures.txt.
# `balance` (laptop): careers 1 to 60 of every class and job, alone and in parties (docs/realm/balance.md).
# `realm` is deterministic, so only ubuntu and msi run it; the laptop and heatherspc spend that time on seeds, careers and frames.
ubuntu: realm world ops queue deep
msi: realm queue deep
laptop: frames balance queue deep
heatherspc: economy queue deep
# `--ci-covered` (flag, optional per machine): the `realm` job is skipped unless the merge touched Windows-only paths CI does not test (README, "CI overlap").
# `queue` (all four): between merges the station takes the next job of the work queue (branch station-queue, loaded with tools/station/queue.sh,
# see README) and falls back to `deep` only when the queue has nothing for this machine. A merge still comes first and interrupts a long job.
